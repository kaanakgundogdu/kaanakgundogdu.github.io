# kaanakgundogdu.github.io

Personal site, blog and CV of Kaan Akgündoğdu.

Live: https://kaanakgundogdu.github.io

Built with [Zola](https://www.getzola.org).

```sh
zola serve
zola build
```

New post: `content/blog/<slug>/index.md`, images next to it.
